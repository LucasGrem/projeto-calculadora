# 🧮 Calculadora Web

**Aplicação web interativa para realização de cálculos matemáticos básicos**  
*Projeto desenvolvido para prática de lógica de programação e manipulação do DOM com JavaScript*

---

## 📋 Sobre o Projeto

A **Calculadora Web** é uma aplicação desenvolvida com HTML, CSS e JavaScript puro (Vanilla JS) que reproduz o funcionamento de uma calculadora digital tradicional. O foco do projeto é consolidar o controle de eventos de clique, atualização dinâmica do visor e validação de expressões matemáticas diretamente no navegador.

## ✨ Funcionalidades

### ✅ **Operações Matemáticas Básicas**
- Suporte para adição (`+`), subtração (`-`), multiplicação (`*`) e divisão (`/`)
- Cálculo de números inteiros e decimais (ponto flutuante)
- Avaliação de expressões sequenciais com exibição imediata do resultado

### ✅ **Controles do Visor**
- Limpeza total do visor (`C` / `AC`) para iniciar um novo cálculo
- Apagamento individual do último caractere digitado (`DEL` / `⌫`)
- Tratamento básico para evitar erros de sintaxe ou divisões inválidas

### ✅ **Interface Responsiva e Intuitiva**
- Layout organizado em grade (CSS Grid) simulando o teclado numérico físico
- Feedback visual ao passar o cursor (`hover`) e pressionar os botões (`active`)
- Adaptação para visualização em telas de desktops, tablets e smartphones

## 🛠️ Tecnologias Utilizadas

### **Frontend**
- **HTML** — Estruturação semântica do visor e dos botões da calculadora
- **CSS** — Estilização moderna, alinhamento com Flexbox/Grid e responsividade
- **JavaScript** — Lógica das operações, captura de eventos e manipulação do DOM

### **Ferramentas**
- **VS Code** — Ambiente de desenvolvimento integrado
- **Git & GitHub** — Versionamento e hospedagem do código-fonte

## 🎓 Contexto Educacional

Este projeto foi desenvolvido para praticar fundamentos essenciais do desenvolvimento front-end, aplicando conceitos como:

- Manipulação de elementos e eventos do DOM (`addEventListener`)
- Lógica condicional e tratamento de strings/números em JavaScript
- Organização de layout de botões utilizando CSS Grid
- Boas práticas de estruturação de arquivos (`index.html`, `style.css` e `script.js`)
